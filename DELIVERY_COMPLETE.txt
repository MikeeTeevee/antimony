================================================================================
SCORING ALGORITHM
================================================================================

Completion State Scores:
  not_started = 0.0 (0%)
  partial     = 0.5 (50%)
  complete    = 1.0 (100%)

Readiness Calculation:
  For each question:
    score = completionState.getScore()
    weight = question.weight || (1.0 / totalQuestions)
    totalScore += score * weight

  Readiness = (totalScore / totalQuestions) × 100%

Example:
  27 total questions
  12 complete (12.0 points)
  6 partial (3.0 points)
  9 not started (0.0 points)
  ──────────────────────
  Total: 15.0 / 27 = 55.6% readiness

  Status: "Not ready (24.4% more work needed)"

Readiness Thresholds:
  SOX: 80% → "Ready to engage auditors"
  Future frameworks: Extensible

API ENDPOINTS (9 TOTAL)
================================================================================

All endpoints require Firebase auth token:
  Authorization: Bearer <firebase-id-token>

Questions:
  GET /questions                 → List questions (filter by category optional)
  GET /questions/:questionId     → Single question

Assessments:
  GET /assessments               → All user assessments
  GET /assessments/:questionId   → Single assessment
  POST /assessments/:questionId  → Create/update assessment
  DELETE /assessments/:questionId → Delete assessment

Readiness:
  GET /readiness                 → Calculate readiness metrics

Dashboard:
  GET /dashboard                 → Complete dashboard data

Health:
  GET /health                    → Service health check

Response Format:
{
  "success": true/false,
  "data": { ... },
  "error": "...",
  "timestamp": "2024-01-20T..."
}

DEPLOYMENT (5 MINUTES)
================================================================================

1. Deploy Cloud Functions:
   cd functions && npm install && firebase deploy --only functions

2. Update API URL in compliance_api_client.dart:
   baseUrl: 'https://us-central1-YOUR_PROJECT_ID.cloudfunctions.net/api'

3. Seed SOX questions:
   npm run build
   node -e "require('./lib/seed').initializeComplianceData()"

4. Set Firestore security rules (template provided in docs)

5. Test:
   final client = ComplianceApiClient();
   final dashboard = await client.getDashboard();
   print(dashboard.metrics.readinessPercentage);
